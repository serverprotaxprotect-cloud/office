GeeBharat Portal Autofill Extension Setup

Ye single Chrome extension GST aur Income Tax dono portal ke liye kaam karega. Chrome security ke karan one-click install allowed nahi hota, isliye ek baar manually load karna hoga.

  1. Download Autofill Extension button se ZIP download karein.
  2. ZIP ko extract karein. Extracted folder ka naam geebharat-autofill rahega.
  3. Chrome me chrome://extensions open karein.
  4. Developer mode ON karein.
  5. Load unpacked click karke extracted geebharat-autofill folder select karein.
  6. Agar purani separate extensions installed hain, to GeeBharat GST Autofill aur GeeBharat Income Tax Autofill remove/disable kar dein.
  7. GeeBharat me GST Clients ya Income Tax Clients list se Login click karein.
GST: ID/password autofill hoga. Captcha aur final login manual rahega.
Income Tax: PAN/user ID, Continue, secure checkbox, password, Continue flow automatic chalega.
Extension credential store nahi karta. Har Login click par short-lived one-time token banta hai.
