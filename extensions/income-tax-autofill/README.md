# GeeBharat Income Tax Autofill Extension

Internal unpacked Chrome extension for Income Tax portal login automation.

## Install

1. If you downloaded the ZIP from GeeBharat, extract it first.
2. Open Chrome and go to `chrome://extensions`.
3. Enable `Developer mode`.
4. Click `Load unpacked`.
5. Select the extracted `income-tax-autofill` folder.

## Use

1. Open GeeBharat Office.
2. Go to `Income Tax Clients`.
3. Click `Login` on an Income Tax client row.
4. Income Tax portal opens and the extension fills PAN/user ID, clicks Continue, ticks secure access checkbox, fills password, and clicks Continue.

The extension does not store credentials. Each token is one-time and short-lived.
