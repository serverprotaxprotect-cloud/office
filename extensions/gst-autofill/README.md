# GeeBharat GST Autofill Extension

Internal unpacked Chrome extension for GST portal autofill.

## Install

1. If you downloaded the ZIP from GeeBharat, extract it first.
2. Open Chrome and go to `chrome://extensions`.
3. Enable `Developer mode`.
4. Click `Load unpacked`.
5. Select the extracted `gst-autofill` folder.

## Update

After downloading a new version, extract it and click `Reload` on the GeeBharat GST Autofill extension in `chrome://extensions`.

## Use

1. Open GeeBharat Office.
2. Go to `GST Clients`.
3. Click `Login` on an allowed GST client row.
4. GST login page opens and the extension autofills username/password.
5. Complete captcha and login manually.

The extension does not store credentials. Each autofill token is one-time and short-lived.
